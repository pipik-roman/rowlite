## Architectural Optimizations Applied

1. **Asymmetric CLI vs. MCP Surface**: Removed non-AI human CLI options (`--dry-run`, `--all`, `--if-checksum`, and redundant positional slicing `head`/`tail`/`offset`/`limit` on `update`, `delete`, and `count`).
2. **Shared Server-Level Instructions (`mcp.ServerOptions.Instructions`)**: Moved cross-cutting filter (`==, !=, like, regex`) and sort (`Col:asc|desc`) syntax rules to the MCP initialization handshake instead of repeating them inside every tool schema.
3. **Zero-Tag Self-Describing Properties**: Omitted redundant `jsonschema` descriptions on self-explanatory property names (`file`, `columns`, `unique`, `limit`, `offset`, `row`, `set`).
