# Documentation Assets

This directory contains static visual media and recorded animations for Rowlite documentation.

## Media Inventory
- `rowlite-demo.gif`: Terminal animation recorded via Charmbracelet VHS tape specification and Python generator (`docs/demo/generate_gif.py`), executing live CLI commands to demonstrate table initialization, auto-increment appends with auditing, querying via `pretty` box formatting, precise row updates, and disk verification.
