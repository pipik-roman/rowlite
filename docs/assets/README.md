# Documentation Assets

This directory contains static visual media and recorded animations for Rowlite documentation.

## Media Inventory
- `rowlite-demo.gif`: Complete terminal hero animation recorded via Python generator (`docs/demo/generate_gif.py`), demonstrating table initialization, auto-increment appends with auditing, querying via `pretty` box formatting, precise row updates, and disk verification.
- `rowlite-demo-part1.gif`: Split demonstration (Part 1 - Creation & Querying): `rowlite init`, `rowlite append` (2 rows), and `rowlite list --format pretty`.
- `rowlite-demo-part2.gif`: Split demonstration (Part 2 - In-Place Mutation & Verification): `rowlite update` and `cat tasks.md`.
